Entry for the make.fun bounty **"Loading Screen Gold: A Tip in 200 Characters"** — one sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer.

## The tip

> Tip: while this loads, your AI agent is reading the file you swore you'd refactor — and it has questions. You have four seconds to prepare answers.

(147 characters)

## How it works

`main.py` writes the tip above to `/output/entry.txt` (UTF-8), creating `/output` if needed and asserting the 1–200 character gate before writing.
